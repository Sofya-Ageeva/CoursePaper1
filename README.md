# Приложение для анализа финансовых транзакций

## Описание

Веб‑приложение для анализа банковских транзакций с генерацией JSON‑ответов для веб‑страниц.

## Функционал


* Главная страница с приветствием, данными по картам, топ‑транзакциями, курсами валют и акциями.
* Загрузка данных из Excel‑файлов.
* Фильтрация транзакций по дате.
* Получение актуальных курсов валют и цен на акции через API.

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv .venv`.
3. Активируйте его:
   * Windows: `.venv\Scripts\activate`.
   * Linux/Mac: `source .venv/bin/activate`.
4. Установите зависимости: `poetry install`.
5. Создайте `.env` из шаблона `.env_template`.
6. Запустите приложение: `python src/main.py`.
