# Проект системы анализа финансовых транзакций
## Цель проекта:
Создание локального приложения для анализа банковских транзакций на основе данных из Excel‑файла. 
Система предоставляет сводную информацию по финансам, инструменты для накопления средств и поиска транзакций 
с номерами телефонов.
# Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/Sofya-Ageeva/CoursePaper1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

# Функционал проекта
1. Главная страница (home_page)
- формирует JSON с данными для главной панели;
- выводит персонализированное приветствие (зависит от времени суток);
- показывает данные по картам: последние 4 цифры номера, общие расходы за период, начисленный кешбэк (1 % от расходов);
- отображает топ‑5 самых крупных расходов за период (дата, сумма, категория, описание).

2. Инвесткопилка (investment_bank)
- рассчитывает сумму для откладывания в копилку с округлением покупок до заданного шага;
Поиск транзакций с номерами телефонов (search_by_phone_numbers):
- находит транзакции, в поле «Описание» которых есть последовательности цифр, похожие на телефонные номера;
- поддерживаемые форматы:
+7 ХХХ ХХХ‑ХХ‑ХХ;
8 ХХХ ХХХ‑ХХ‑ХХ;
ХХХ‑ХХ‑ХХ (локальные номера);
результат: список транзакций с найденными номерами (дата, сумма, описание).

3. Статистика расходов (в рамках main.py):
- подсчитывает итоговые финансовые показатели за период;
выводимые данные:
- всего транзакций — общее количество операций;
- общие расходы — сумма всех расходных операций (по модулю);
- общие доходы — сумма всех приходных операций;
- чистый баланс — разница между доходами и расходами (доходы − расходы).

4. Загрузка данных (load_transactions)
- читает данные из Excel‑файла (operations.xlsx);
- обязательные колонки в файле:
Номер карты (например, 400000****1234);
Сумма операции (отрицательная для расходов, положительная для доходов);
Категория (например, «Продукты», «Транспорт»);
Описание (текст, может содержать комментарии, номера телефонов и т.д.);
Дата операции (формат YYYY-MM-DD HH:MM:SS).

5. Логирование
- ведёт запись основных событий в консоль (уровень INFO);
- фиксирует: запуск модуля, успешную загрузку данных, ошибки (например, отсутствие файла).

## Тестирование существующих функций
1. Реализованы тесты c покрытием более 80 % созданных модулей.
2. В тестах добавлены фикстуры и параметризация
3. Тесты, работающие с внешними источниками, используют `Mock` и `patch` 
для изоляции от внешних зависимостей 
4. Для запуска теста необходимо ввести в командной строке следующую команду:
```
pytest
```
5. Результаты тестирования содержаться в папке `htmlcov/`)
